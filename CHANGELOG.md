# Changelog

## 1.0.0 (2026-10-09)

First release of Kast, a fork of [Lanjut](https://github.com/rimzzlabs/lanjut).

- Kast brand; interface in Lithuanian, English, and Russian; each résumé keeps
  its own language
- Ten templates with ATS and design modes; accent color, photo with crop,
  contact icons, QR code
- New sections: volunteering, courses, publications, references, hobbies,
  driving licence, salary expectations, availability; languages rated for
  speaking, understanding, and writing
- Local ATS check with a 0–100 score, fixes, keyword match, and a PDF
  text-layer check
- PDF import with column and sidebar detection, furniture filtering, badges
  kept as metadata, and a review step
- Optional AI assistant with the user's own Anthropic or Gemini key: masking,
  consent, diff review, estimates, batch mode
- Version history, vacancy labels with status, cover letter, Europass export,
  backup and restore, offline PWA, settings, about, and privacy pages
